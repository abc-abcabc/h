# 지금 뜨는 경제·정치 영상

유튜브에서 지금 뜨는 경제·정치 영상과 쇼츠를 모아 보여주는 웹앱입니다. Vercel에 올려서 씁니다.

## 폴더 구조

```
index.html        화면 (탭, 필터, 정렬, 영상 재생 창)
api/videos.js     Vercel 서버 함수 (유튜브 API 호출, API 키 보관)
package.json
```

## 1. 유튜브 API 키 발급 (무료, 5분)

1. https://console.cloud.google.com 접속 → 상단에서 **새 프로젝트** 만들기
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
4. 만들어진 키를 눌러 **API 제한사항 → 키 제한 → YouTube Data API v3** 만 체크 (권장)

## 2. Vercel 배포

1. 이 폴더를 GitHub 저장소에 올리고 Vercel에서 **Add New → Project** 로 가져오기
   (또는 터미널에서 이 폴더로 이동해 `npx vercel`)
2. Framework Preset은 **Other**, 빌드 설정은 비워 둡니다.
3. **Settings → Environment Variables** 에 추가
   - Name: `YOUTUBE_API_KEY`
   - Value: 1번에서 받은 키
4. 환경변수를 넣은 뒤 **Redeploy** 해야 적용됩니다.

## 탭 설명

| 탭 | 데이터 | 서버 갱신 주기 |
|---|---|---|
| 뉴스·정치 급상승 | 유튜브 공식 한국 인기 급상승 차트, 뉴스/정치 카테고리 | 10분 |
| 경제·증시 | 최근 48시간 업로드 영상 중 경제/증시/주요 채널 조회수 상위 50개 | 1시간 |
| 정치 | 최근 48시간 업로드 영상 중 정치/국회 키워드 조회수 상위 50개 | 1시간 |

- 화면은 5분마다 자동 갱신되지만, 서버 캐시 덕분에 유튜브 API는 위 주기대로만 호출됩니다.
- **급상승 속도** = 조회수 ÷ 업로드 후 경과 시간(시간당 조회수). 실시간 화제성이 높은 영상을 발굴합니다.
- **쇼츠**는 `#shorts` 태그 및 영상 길이를 결합 분석하여 가로형 뉴스 리포트가 쇼츠로 잘못 분류되는 것을 방지합니다.
- **결과 내 검색** 기능으로 불러온 영상 목록에서 키워드나 채널명을 즉시 필터링할 수 있습니다.

## API 사용량

무료 할당량은 하루 10,000단위입니다. 검색은 1회 100단위로 비싸서, 위 갱신 주기 기준 하루 약 5,000단위를 씁니다.
키워드를 바꾸거나 주제를 늘리려면 `api/videos.js` 상단의 `TOPICS` 를 수정하세요. 검색형 주제를 추가할 때는 캐시(`cache`, 초)를 3600 이상으로 두는 것을 권장합니다.
